# OPERAZIONE PC — La sfida del laboratorio

Gioco didattico in italiano per studenti di prima superiore, realizzato con HTML, CSS e JavaScript vanilla.

**[Gioca nel browser](https://palermoalfio94.github.io/tecnicoInformatico/)**

## Le quattro missioni

1. **Il computer smontato**: riconoscere dieci componenti della postazione.
2. **Input o Output?**: classificare quindici dispositivi con trascinamento o pulsanti.
3. **La diapositiva distrutta**: sistemare una diapositiva con un editor interattivo.
4. **La password segreta**: risolvere cinque enigmi e aprire la cassaforte.

Punteggio massimo: **80 punti**. Il gioco include feedback, indizi, salvataggio locale dei progressi, audio opzionale e attestato stampabile o scaricabile.

## Utilizzo

Aprire il link del gioco, scegliere un nickname di fantasia e iniziare. Non servono account.

Per usarlo offline, scaricare `index.html` e aprirlo con Chrome o Edge. Tutte le risorse sono incorporate: non occorre installare dipendenze.

I progressi restano nel browser e sul dispositivo utilizzato. Sui computer condivisi premere **Ricomincia** quando cambia lo studente.

La [guida docente](LEGGIMI-DOCENTE.txt) descrive punteggi e propone una lezione di circa 50–55 minuti. Il tempo di una partita dipende dal ritmo e dalle attività di discussione.
